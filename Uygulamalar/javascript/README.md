## JavaScript Nedir?

JavaScript, web sayfalarını dinamik ve etkileşimli hale getiren programlama dilidir.

- **HTML** → Sayfanın yapısı (iskelet)
- **CSS** → Sayfanın görünümü (kıyafet)
- **JavaScript** → Sayfanın davranışı (hareket, etkileşim)

```html
<!DOCTYPE html>
<html>
<head>
    <title>İlk JavaScript Programım</title>
</head>
<body>
    <h1>Merhaba Dünya!</h1>
    <script>
        // Bu bir JavaScript kodudur
        alert("JavaScript çalışıyor!");
    </script>
</body>
</html>
```

> **Not:** JavaScript kodları `<script>` etiketi içine yazılır veya `.js` uzantılı ayrı dosyalara kaydedilir.
